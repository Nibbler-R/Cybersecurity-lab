# Cybersecurity Lab

A personal hands-on cybersecurity lab built with Kali Linux to develop practical skills in Linux, networking, Bash scripting, web security, and penetration testing.

This repository documents my learning process through practical exercises, lab work, scripts, and penetration-testing reports.

## Areas of Practice

* **Linux:** command-line navigation, file management, permissions, and system services
* **Bash:** variables, user input, conditionals, and basic scripting
* **Networking:** IPv4/IPv6, MAC addresses, ARP, routing, DNS basics, TCP/UDP, and ports
* **Network Security:** Nmap host discovery, port scanning, and service/version detection
* **Web / HTTP:** HTTP requests, status codes, APIs, JSON, and request inspection
* **Authentication:** cookies, authentication tokens, authentication vs. authorization
* **Web Security:** OWASP Juice Shop, endpoint enumeration, API testing, and authorization testing
* **Services:** Apache2, SSH, and PostgreSQL
